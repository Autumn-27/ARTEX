# chains-web L3 决策骨架(场景→判据→转向;蒸馏自 chains 语料,完整 Q&A 见 skills/chains-web/refs/)
- 场景:疑似注入参数|判据:看可复现的真假分叉而非报错——报错只说明语法变了,分叉才说明表达式进了执行逻辑|转向:无分叉换时间盲/OOB,再换注入位置(body/header/cookie/JSON)
- 场景:注入成立选信道|判据:联合>报错>布尔>时间,取信息量最高且稳定者;能出网则 DNS 外带快几个数量级|转向:读写被限转凭据收割(后台hash/密钥),云RDS无OS面转数据+云身份
- 场景:payload被WAF拦|判据:200不等于打通,WAF会伪造200,先做良性/恶意对照再信响应;二分定位被拦token,一次只改一个变量|转向:换编码/位置/Content-Type,云WAF溯源站IP直连
- 场景:发现上传点|判据:先传良性文件看三件事——路径回显、重命名策略、可否直接访问,再谈webshell|转向:随机名无回显转"上传作原语"(XXE/存储XSS/phar/LFI组合)
- 场景:上传白名单只收图片|判据:落地≠执行,访问返回源码即未解析;校验与中间件取后缀算法不一致才有缝|转向:转解析漏洞/.htaccess;磁盘落地被杀绝转内存马(需先有一次执行)
- 场景:可疑序列化数据|判据:剥编码看魔数:rO0=Java、O:数字=PHP、\x80\x03=pickle;URLDNS先验"确实反序列化且出网"|转向:无gadget转SSRF/情报点,白名单filter转二次反序列化或换面
- 场景:吃URL参数疑SSRF|判据:先验回连源IP是目标服务端出口(防CDN/浏览器伪SSRF),再测能否碰内网;云上首打元数据IMDS|转向:白名单转302/DNS重绑定/解析差异,盲打转"改状态"的内网服务
- 场景:输入被回显疑SSTI|判据:唯一判据是{{7*7}}回显49;curl裸取出49=SSTI、须JS执行才出=CSTI;先指纹引擎再上链|转向:沙箱锁死降级读SECRET_KEY/配置,伪造session常比半残RCE值钱
- 场景:XML入口疑XXE|判据:良性外部实体指向带外地址,回连=解析器活+出网;盲XXE先DNS探活再参数实体外带|转向:DOCTYPE被禁转XInclude/本地DTD error-based,全禁降级为免校验SSRF
- 场景:疑命令注入|判据:sleep延时须与设定线性对应(3s→3s、7s→7s)才排除抖动误报;带外优先于时间盲|转向:分隔符全灭转argument injection(tar/find/curl危险选项),数组式execve放弃引号游戏
- 场景:带ID请求疑IDOR|判据:双账号对照——B会话读到A埋唯一标记的私有资源才算越权,排除公开数据误报;读写分别验证|转向:403换传参通道/方法/对象类型;批量/导出接口常是鉴权断层
- 场景:JWT/认证攻击|判据:先跑alg=none、RS→HS混淆、kid/jku四件套;签名铁打转生命周期(exp不校验、注销不失效、refresh不轮换)|转向:伪造不动转窃取泄露(JS/git/日志),认证强转合法身份下的越权
- 场景:识别出CMS|判据:品牌+精确版本才映射nday;优先级:未授权RCE>未授权读写>认证后RCE;版本新转插件/主题(更新滞后重灾区)|转向:已知洞全灭转二次开发接缝、配置泄露(.git/备份)、逻辑漏洞
- 场景:漏洞落地shell前|判据:先填满三格——数据库类型、当前用户权限、DB与Web是否同机;先读已知系统文件验证FILE权限再谈写|转向:写不了转读配置收凭据横向;落地被查杀转内存马
- 场景:单点久攻不下|判据:连续15~25次同质响应(无新状态码/长度/时序差异)即信息榨干,立即转向;有信号梯度才续|转向:按攻击面矩阵换维——换参数/换洞类/换入口/换资产,记录挂起不死磕
