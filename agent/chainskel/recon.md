# chains-recon L3 决策骨架(场景→判据→转向;蒸馏自 chains 语料,完整 Q&A 见 skills/chains-recon/refs/)
- 场景:只有根域名/公司名|判据:先扩面后打点,确权边界→组织关联→资产收敛;多源交叉验证归属,新增资产趋零且无新主体即收敛|转向:名称反查噪声大就换指纹锚点(已知IP/favicon hash/证书SAN做种子)
- 场景:枚举子域|判据:永远被动优先(CT/被动DNS/测绘/搜索,零告警),主动爆破用按已知命名规律定制的字典补盲区|转向:DNS被限速就换多解析器轮询降并发,或转ASN/证书SAN/favicon反查
- 场景:子域爆破疑似泛解析|判据:随机超长不存在子域也解析成功=泛解析,按黑洞IP集合过滤,真实子域叠加HTTP响应/证书SAN二次判定|转向:内容也泛化就靠CT/被动DNS历史;分不清视为ROI低,撤去IP段直扫/favicon关联
- 场景:全站挂CDN|判据:多路找源(历史DNS/未接CDN的邮件测试子域/同证书同favicon反查),Host碰撞返回一致业务内容即坐实源站|转向:多路无果就放弃穿透转应用层,或打未上CDN的姊妹资产,源站不是目的
- 场景:端口扫描与被封|判据:先top端口拿面、高价值主机再全端口;整段同时静默=防火墙介入;关键判断换工具换源IP复核|转向:大量超时=触发限速,降速换出口;IPS盯上就转空间测绘零接触查端口
- 场景:指纹识别置信度|判据:banner只当线索,多特征投票(cookie/错误页/TLS指纹)一致才可信;识别到栈类别+版本区间即可选武器;版本只排序候选,漏洞靠行为探测证实|转向:识别不出发畸形输入看报错;自研无指纹转功能点驱动
- 场景:JS端点挖掘|判据:按chunk映射表判抽全;优先级=admin/internal>UI无入口的隐藏接口>带id越权>上传导出>SSRF服务|转向:静态抽不到就headless hook网络层录运行时URL;强混淆只捞字符串常量
- 场景:接口未授权/越权验证|判据:不带token/失效token/低权token三组对比,200且真数据即未授权,缺失常成片;越权须双账号对照拿到他人数据|转向:全401先搞低权身份再转IDOR;改id被挡就换参数位/数组包裹/旧版本
- 场景:泄露狩猎顺序|判据:先扫暴露即高危(.git/.svn/.env/备份/swagger)再目录爆破;字典随栈切换;拿到①可验证凭据②源码③接口清单任一即转利用|转向:被WAF墙了转公网被动面(代码平台/Wayback/搜索语法)
- 场景:挖到疑似密钥凭据|判据:区分设计公开key与服务端密钥,用官方只读whoami接口最小验活;可直达代码执行/数据库/云管理面=最高价值,尽快验证防轮换|转向:失效别丢,按同pattern去历史JS/移动包/git历史找活的
- 场景:OSINT与凭据攻击|判据:先定邮箱命名格式批量生成;泄露库旧口令提取基词做年份符号变形;喷洒前摸清锁定阈值,一轮1~2口令宽面错峰|转向:人无线索转机器凭据(API key/连接串);MFA封死转预认证漏洞或遗留入口
- 场景:隐藏参数挖掘|判据:字典源=本站JS>历史快照>同框架参数集>通用字典;多维基线(长度/状态码/耗时/报错)稳定复现变化才算被消费|转向:来源榨干、组合无新分支即收益趋零,过六维清单(名/位置/编码/方法/类型/认证态)后转移
- 场景:爆破全是403/302|判据:先用随机路径建基线,随机路径也403=统一拦截假阳性;403=存在但禁访比404值得挖;区分WAF的403(改编码换源)与应用的403(改路径头方法)|转向:绕过递减无效即止损,换子域/移动端API
- 场景:侦察何时算够|判据:硬标准=能写出可证伪假设"服务P有漏洞V,手法M预期结果R";多源产出高度重叠=发现收敛;低噪可回滚五成就打,高噪七八成才动|转向:不成假设先组合弱信息、倒推攻击链缺口;维度(人/供应链/移动/云)未穷尽不算死
